# کلاینت ذکرانه

اپ universal ذکرانه با Expo SDK 57، Expo Router، HeroUI Native، Uniwind و SQLite.

همه فرمان‌ها با Bun اجرا می‌شوند:

```sh
bun run start
bun run android
bun run export:web
bun run serve:pwa
```

ساخت‌های انتشار پس از ورود به حساب Expo:

```sh
bun run build:preview
bun run build:production
bun run deploy:web
```
